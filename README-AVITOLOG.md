# Авитолог — локальная панель продавца

## Запуск
Установите Node.js 20+. Скопируйте .env.example в .env, задайте APP_PASSWORD и длинный SESSION_SECRET, затем выполните npm install и npm run dev. Откройте http://127.0.0.1:3001. Пароль по умолчанию: 132213.

Приложение слушает только 127.0.0.1 и предназначено для локального использования. Не выставляйте его напрямую в интернет. Для удалённого размещения нужны HTTPS, собственные пароль/секрет, защищённое хранилище сессий и настройка хостинга.

## Возможности
Четыре раздела, серверная авторизация с HttpOnly cookie, очередь черновиков, загрузка фотографий, SQLite, демонстрационная обработка, три ориентира цены, редактирование, демо-публикация и календарь слотов.

## Ограничения
Avito MCP не подключён: публикация работает только в демо-режиме, статистика и реальные предложения недоступны, сообщения покупателям не отправляются. core/bridge.js содержит точку подключения официальных инструментов Avito. Фото и база сохраняются локально в uploads/ и data/.
