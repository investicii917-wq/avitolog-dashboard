# Авитолог — сайт объявлений

Опубликованная версия: https://investicii917-wq.github.io/avitolog-dashboard/

## Подключение

На первом экране пользователь вводит адрес приватного репозитория и секретный ключ. Ключ сохраняется только в браузере этого устройства и используется для прямого обмена с GitHub Contents API.

## Синхронизация

- новое действие сайта сразу записывается в `inbox`;
- результат обработчика приходит через `outbox`;
- компактный снимок `state/site-state.json` даёт второму устройству актуальный список объявлений и календарь;
- фоновая проверка результатов на сайте выполняется раз в пять минут.

## Экранные разделы

- `/analytics` — интерес к опубликованным объявлениям и воронка;
- `/list/ready` — объявления в обработке, готовые и архивные;
- `/list/published` — опубликованные объявления, предложения и переписки;
- `/new` — создание объявления до десяти фото, настройка карточек и параметров товара;
- `/calendar` — окна самовывоза и встречи.

## Локальный обработчик

Рабочий компьютер читает очередь раз в час, Avito API — раз в две минуты, статистику — раз в шесть часов. Он записывает результаты обратно в `outbox`. Подробный формат приведён в `ARCHITECTURE.md`.

Ключи Avito и ключи репозитория не хранятся в этом репозитории.
