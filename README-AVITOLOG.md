# Авитолог

Автономный локальный визуальный прототип панели продавца.

В текущей версии нет привязки к Авито, MCP, Antigravity или любому внешнему серверу. Приложение ничего не отправляет наружу. Публикация и принятие оффера работают как демонстрационные локальные переходы интерфейса.

## Запуск

1. Установить Node.js 20 или новее.
2. Скопировать файл .env.example в .env.
3. Выполнить npm install.
4. Выполнить npm run dev.
5. Открыть http://127.0.0.1:3001.

Пароль по умолчанию: 132213.

## Что уже есть

- вход с серверной сессией;
- четыре раздела панели;
- создание черновика и загрузка фотографий;
- SQLite база для локальных данных;
- обработка черновика в демонстрационном режиме;
- варианты цены, редактирование и локальная публикация;
- календарь слотов самовывоза.

Подключение конкретного MCP-сервера добавляется отдельной задачей после явной команды и получения его точного формата.
