# Приёмка изображений и обмена

## Критические ошибки: блокируют выдачу как готового результата

- Другая форма, модель, раскладка, число деталей, цвет или состояние товара.
- Изменённый логотип, искажённые значимые надписи, скрытый дефект.
- Придуманные характеристики, документы, отзывы, оценки, скидки, комплект или размеры.
- Недостающая карточка; разные пропорции в серии; пустой/повреждённый файл.
- Не тот requestKey, itemId, sourceEventId; результат старого задания заменяет новый.
- Студийная основа designer не проверена либо отсутствует привязка к ней.

## Проверки отдельного файла

1. Открыть файл визуально, проверить формат и реальные ширину/высоту.
2. Сверить с оригиналом силуэт, клавиши/разъёмы/швы/маркировку, дефекты.
3. Прочитать текст и сверить посимвольно; нет несуществующих букв и смешанной раскладки.
4. Проверить целевой сюжет: общий план или намеренная деталь, не случайный обрез.
5. Уменьшить предпросмотр до ширины мобильного экрана: товар различим, важный текст читаем.
6. Проверить композицию: нет перекрытого товара, лишних предметов и ложного масштаба.

## Проверки серии

Количество соответствует count. Пропорции точно 4:3 либо 3:4 у всех. Общие свет/палитра/типографика. Сюжеты различны и логичны. Все факты привязаны к источникам. Порядок фотографий помогает рассмотреть товар. Исходники доступны для повторной проверки. Критические ошибки нельзя компенсировать средней оценкой остальных пунктов.

## Проверки транспорта

Прогнать 3 стиля × 3 формата × количества 1/3/10, выключенную генерацию, пустые заметки, отсутствие фото, старое объявление без cardFormat. Проверить сохранение черновика, повторное открытие, сериализацию манифеста, скачивание новым устройством, отсутствие повторной генерации при неизменном сохранении. При смене текста/формата/фото requestKey меняется. При выключении генерации устаревший результат не применяется.

Отдельно: прервать загрузку одного файла, вернуть неправильный count/ratio/style/key, повторить событие. Не отмечать готовность и не терять исходные фотографии. Сеть может отказать: гарантия системы — сохранённое задание и понятный повтор, не обещание отсутствия любых ошибок.

## Исправление

Один целевой повтор для конкретного дефекта, затем новая проверка. При повторном искажении предмета не расходовать лимит бесконечно: сохранить исходник и поставить needs_input/quality_failed, предложить точный монтаж с сохранением объекта либо более качественный исходник. Не менять инструмент или подключать платный API без соответствующего разрешения.


## Обязательное правило обложки — 2026-10-17
Это уточнение заменяет прежнее требование одинаковых пропорций ВСЕХ файлов. Первая карточка всегда физически квадратная (1:1, width=height). Вторая и следующие — все 4:3 или все 3:4 по выбранному формату. При auto выбрать формат только для карточек 2..N. При count=1 выдать только квадратную обложку. Число включает обложку. Не менять выбранный домашний/студийный/дизайнерский стиль. Все важные детали и надписи должны помещаться внутри кадра без обрезания. Обложка должна привлекать внимание честной композицией, без выдуманных свойств. Результат передаёт реальные width/height каждой карточки, coverAspectRatio=1:1 и aspectRatio для остальных.
