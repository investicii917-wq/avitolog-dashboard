# Отчёт исходной проверки и оптимизации транспорта

Дата: 2026-10-20.

## Исходное состояние

- Рабочая точка восстановления: Git-коммит `928100d`.
- Резерв создан в `C:\Users\Ardor\Avitolog-Backups\baseline-2026-10-19-928100d` с контрольными суммами.
- Визуальные экраны, APK, Avito API и реальная база в этой работе не менялись.

## Найденные причины задержек

1. Любое сохранение планировало полную фоновую проекцию всего состояния.
2. Перед заданием заново записывались фото как вложения задачи.
3. Перед отправкой выполнялось восстановление исходников и истории, даже если на сервере уже были ссылки.
4. Ошибка одной записи завершала цикл и откладывала следующие задания.

## Внесённые изменения

- Убран запуск полной проекции из каждого локального сохранения.
- Введён совместимый `transportVersion: 2`.
- Медиа записываются один раз в `images/...`; следующие задачи передают ссылки на них.
- Быстрая отправка обновляет только `listing.json`, нужный указатель статуса и требуемые данные предложений/диалогов.
- Независимое задание продолжает отправляться, если предыдущее временно не удалось.

## Проверки

- Изолированные проверки сайта: карточки, реестр, повторная доставка, история карточек, календарь и зеркальность `docs/public`.
- Изолированные проверки обработчика: текст, комментарий, канонические исходники, внешние изображения и восстановление после ошибки публикации.

Эти проверки используют подменённый GitHub и Codex CLI. Они не являются обработкой реальных объявлений.
